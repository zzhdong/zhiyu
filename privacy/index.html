知域隐私政策

更新日期：2026年9月26日

首页支持

1. 基本原则

知域只在你主动使用相关功能时访问必要的数据，并尽量把设置、缓存与工具状态保留在设备本地。知域不包含广告 SDK，不使用广告标识符，也不为跨 App 或网站的广告目的跟踪用户。

2. 位置与天气

当你主动选择“使用我的位置”或开始定位测试时，知域会在取得系统授权后获取当前位置。天气查询会把所需的经纬度发送给 Apple Weather（WeatherKit）以及 MET Norway。

MET Norway 的服务条款说明，直接从 App 调用其 API 时，请求 IP 地址以及请求中包含的地理坐标会保存在其访问日志中。知域使用这些数据仅用于提供天气功能，不用于广告跟踪。MET Norway 的数据处理受其自身条款和隐私政策约束。

知域将当前位置写入本地持久化状态前会降低坐标精度；天气小组件不会接收精确经纬度。

3. 本地数据

应用偏好、保存的天气地点、缓存以及小组件共享状态主要保存在设备或 App Group 中。知域没有用户账号系统，也不会把这些本地偏好用于建立广告画像。

4. 相机、麦克风、运动与 Face ID

这些能力仅在你主动开始对应设备测试时调用。相机画面和麦克风测试录音不会由知域上传。Face ID 身份验证由 iOS 的 LocalAuthentication 框架处理，知域不会获得 Face ID 生物特征模板。

5. 照片

为时钟或小组件选择自定义背景时，知域使用系统照片选择器读取你明确选择的图片，并将所需副本保存在 App 的本地/App Group 存储中，以便 App 与小组件显示。知域不会把所选照片上传到自有服务器。

6. 日历、通知与 CloudKit

系统日历仅在你授权并主动使用相关功能时读取或写入。通知权限仅用于你创建的提醒。CloudKit 用于获取和更新节假日数据，不用于建立用户账号或广告跟踪。

7. 设备与网络信息

设备信息和主动测试结果主要在设备本地处理。Wi‑Fi SSID/BSSID 仅在 Apple 公共 API 与系统权限允许时用于本机显示，知域不会为了读取网络名称自动请求定位权限，也不会把该信息上传到自有服务器。

8. 第三方服务

  • Apple Weather / WeatherKit：提供天气数据与官方 attribution。
  • MET Norway：提供天气数据；Terms of Service。
  • Apple CloudKit：用于节假日数据更新。

9. 你的选择

你可以随时在 iOS“设置”中拒绝或撤回定位、相机、麦克风、运动、Face ID 或日历权限，并可在知域中删除保存的天气地点。删除 App 会移除 App 本地保存的数据；此前由你主动写入系统日历的事件属于系统日历数据，不会因卸载知域而自动删除。

10. 联系方式

支持与隐私问题可通过开发者的 GitHub 页面联系：github.com/zzhdong。

ENGLISH

Zhiyu Privacy Policy

Last updated: 26 September 2026

1. Principles

Zhiyu accesses data only when needed for features you actively use and keeps preferences, caches and tool state on device wherever possible. Zhiyu contains no advertising SDK, does not use advertising identifiers, and does not track users across apps or websites for advertising.

2. Location and weather

When you actively choose to use your current location or start the location test, Zhiyu obtains location after iOS permission. Weather requests send the required latitude and longitude to Apple Weather (WeatherKit) and MET Norway.

MET Norway states that direct app API calls store the request IP address and any geocoordinates contained in the request in access logs. Zhiyu uses this data only to provide weather functionality and not for advertising tracking. MET Norway processes its logs under its own terms and privacy practices.

Zhiyu reduces coordinate precision before persisting current-location state locally, and the weather widget does not receive precise coordinates.

3. Local data

App preferences, saved weather places, caches and widget shared state are stored mainly on the device or in the App Group. Zhiyu has no user-account system and does not use these preferences to build advertising profiles.

4. Camera, microphone, motion and Face ID

These capabilities are used only when you actively start the corresponding device test. Zhiyu does not upload camera previews or microphone test recordings. Face ID authentication is handled by iOS LocalAuthentication; Zhiyu does not receive Face ID biometric templates.

5. Photos

When you choose a custom clock or widget background, Zhiyu uses the system photo picker to read the image you explicitly select and keeps the required copy in local/App Group storage. Zhiyu does not upload the selected image to its own server.

6. Calendar, notifications and CloudKit

The system calendar is read or written only after permission and active use. Notification permission is used for reminders you create. CloudKit is used to retrieve and update holiday data, not to create user accounts or for advertising tracking.

7. Device and network information

Device information and interactive test results are primarily processed on device. Wi‑Fi SSID/BSSID is displayed locally only when Apple public APIs and system permissions allow it; Zhiyu does not request location merely to read the network name and does not upload that information to its own server.

8. Third-party services

  • Apple Weather / WeatherKit for weather data and official attribution.
  • MET Norway for weather data; see its Terms of Service.
  • Apple CloudKit for holiday-data updates.

9. Your choices

You can deny or revoke location, camera, microphone, motion, Face ID and calendar permissions in iOS Settings and remove saved weather places in Zhiyu. Deleting the app removes locally stored app data. Calendar events that you explicitly wrote to the system calendar remain system-calendar data and are not automatically removed by uninstalling Zhiyu.

10. Contact

For support or privacy questions, contact the developer through github.com/zzhdong.
