Support

需要帮助？直接联系开发者。

知域由个人开发者维护。遇到问题时，请通过邮件告诉我版本、设备、系统版本和复现步骤；请不要发送与问题无关的精确位置、日历内容或其他敏感信息。

发送邮件
Weather

定位与天气

只有在你主动选择当前位置时才请求定位。如果天气无法更新，请检查网络、iOS 定位权限以及天气页面的数据源状态。

Calendar

日历与提醒

系统日历和通知由 iOS 分别授权。可在“设置 → 隐私与安全性”以及“设置 → 通知”中调整。

Device tests

设备测试

相机、麦克风、Motion、定位与 Face ID 只在你主动开始对应测试时调用；离开测试后会停止相应流程。

Measurement

测量工具

噪音估算需要麦克风权限；暗光画面增强和心率估算需要相机权限，心率估算还会使用后置闪光灯。心率结果仅供日常参考，不用于医疗诊断；噪音结果为未经设备级校准的估算，不能替代专业声级计。

Widgets

小组件

天气小组件在 iOS 提供 Timeline 执行机会时，可使用已保存的区域级地点直接更新 MET Norway 天气，不需要后台定位。实际刷新时机仍由 iOS 系统预算决定；若长时间未更新，可打开知域检查网络与天气数据源状态。

Purchase

购买、账单与退款

知域采用一次性付费下载，当前版本没有订阅或 App 内购买。App Store 账单和退款由 Apple 处理。

English

Support in English

Zhiyu is maintained by an individual developer. For support, email zzhdong@gmail.com. Please include the Zhiyu version, iOS/iPadOS version, device model, affected feature and steps to reproduce, and avoid sending unrelated sensitive information.

When iOS grants a timeline refresh opportunity, the Weather widget can update MET Norway weather using the stored area-level location without invoking Core Location in the widget. Actual refresh timing remains controlled by iOS.

Measurement tools are processed on device. Noise Test provides an uncalibrated estimate and does not replace a professional sound level meter. Heart Rate Test estimates BPM from camera PPG for everyday reference only and is not for medical diagnosis or decisions.

Zhiyu is a one-time paid download. The current version contains no subscriptions or in-app purchases. Billing and refund requests are handled through Apple.
