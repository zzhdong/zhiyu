知域支持

使用帮助、权限说明与问题反馈。

首页隐私政策

联系开发者

知域由个人开发者维护。问题反馈可通过 GitHub Issues 提交，也可查看开发者主页：github.com/zzhdong。

反馈问题时建议包含：知域版本、iOS/iPadOS 版本、设备型号、问题发生的功能页面，以及可复现步骤。请不要公开提交精确位置、日历内容或其他敏感信息。

购买与退款

知域计划作为 App Store 一次性付费下载 App 提供，当前版本不包含订阅或 App 内购买。购买、账单和退款由 Apple 的 App Store 体系处理；如需申请退款或处理账单问题，请使用 Apple 提供的购买支持渠道。

定位与天气

知域仅在你主动选择当前位置时请求定位权限。如果天气无法更新，请检查网络连接、iOS 定位权限，以及天气页面的数据源状态。

日历与提醒

日历事件访问和通知分别由 iOS 权限控制。可在“设置 → 隐私与安全性”及“设置 → 通知”中调整。

设备测试

相机、麦克风、运动传感器、定位与 Face ID 测试只在你主动开始测试时请求对应权限。离开测试后，知域会停止对应测试流程。

小组件

若小组件暂未更新，可先打开知域一次，确认相关功能已有数据，再返回主屏幕。iOS 会根据系统预算决定小组件实际刷新时机。

Support in English

Zhiyu is maintained by an individual developer. For support, open an issue at GitHub Issues or visit github.com/zzhdong. When reporting an issue, include the Zhiyu version, iOS/iPadOS version, device model, affected feature and reproduction steps. Do not post precise location, calendar contents or other sensitive information publicly.

Zhiyu is planned as a one-time paid download with no subscriptions or in-app purchases in the current version. App Store billing and refund requests are handled through Apple.
