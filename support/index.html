HELP & SUPPORT

需要帮助？这里有入口。

先查看相关指南，再联系开发者。请勿发送精确位置、日历内容等不必要的个人信息。

天气小组件为什么不实时更新？

天气小组件可使用已保存的区域级位置通过 MET Norway 独立刷新，不需要后台定位；实际刷新由 WidgetKit 与 iOS 系统预算决定。

天气无法更新？

检查网络、地点、天气数据来源与定位授权。若使用当前位置，需主动选择并授权。

日历提醒没有出现？

分别检查通知权限、提醒规则、专注模式与系统日历授权。

设备测试未获得结果？

设备型号、系统权限和公共 API 会限制部分传感器，部分测试需要真机。

测量工具的噪音、夜视或心率异常？

噪音估算不能替代专业声级计；相机 PPG 心率不用于医疗诊断；夜视只进行暗光画面增强。请按指南检查设备权限。

打开对应指南 ↗

二维码无法扫描或生成？

先确认相机或照片权限；制作二维码后核对内容，外部网址不会自动打开。

打开对应指南 ↗

图片处理或滚动截屏失败？

检查图片与视频导入权限及素材格式；录屏必须主动授权 ReplayKit，滚动过快可能影响拼接质量。
