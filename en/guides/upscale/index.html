USER GUIDE / UPSCALE

Image resolution upscaling

2×/4× interpolation with optional light sharpening.

←Back to all guides28 guide topics

HOW IT WORKS

Process diagram, not an app screenshot
  1. 01

    Open upscale

    Find Resolution Upscaling in Image Studio.

  2. 02

    Choose a source

    Explicitly import an image from Photos or Files.

  3. 03

    Set the scale

    Choose 2× or 4× interpolation and optional light sharpening.

  4. 04

    Preview and export

    Inspect the result on-device before saving or sharing.

Before you begin

This is interpolation, not AI super-resolution. It cannot restore detail absent from the source image.
