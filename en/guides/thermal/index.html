USER GUIDE / THERMAL

Thermal-style camera effect

Apply false colours to an ordinary camera image.

←Back to all guides28 guide topics

HOW IT WORKS

Process diagram, not an app screenshot
  1. 01

    Open measurement

    Find the low-light camera tool and its visual effects.

  2. 02

    Allow camera access

    Grant permission when you actively start the camera.

  3. 03

    Choose an effect

    Select the available thermal-style false-colour mode.

  4. 04

    Finish intentionally

    Capture a still if needed or leave the camera screen.

Before you begin

This is not infrared thermal imaging. It cannot measure temperature or detect actual heat sources.
