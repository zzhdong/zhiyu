HELP & SUPPORT

Help when you need it.

Start with a guide or contact the developer. Avoid sending sensitive personal information.

Why isn't my weather widget updating?

The Weather widget can refresh through MET Norway using saved area-level coordinates, without background location. WidgetKit and iOS decide the refresh budget.

Read the guide ↗

Weather not updating?

Check the network, selected location, data provider status and optional location permission.

Read the guide ↗

Reminders not appearing?

Review notification permission, reminder settings, Focus and calendar access.

Read the guide ↗

Can't complete a device test?

Device capabilities and public API permissions differ; some tests need actual hardware.

Read the guide ↗

Measurement not working?

Noise estimates are not a calibrated sound level meter; camera PPG is not a medical diagnosis; low-light enhancement requires visible light.

Read the guide ↗

Problems scanning or creating a QR code?

Check camera or photo access. Review generated content; scanned external links never open automatically.

Read the guide ↗

Image processing or scrolling capture failed?

Check imported image/video formats; recording needs explicit ReplayKit permission and very fast scrolling can reduce stitching quality.

Read the guide ↗

Purchases, billing and refunds

Zhiyu is a one-time paid download with no subscription or in-app purchases. Use Apple App Store purchase history and Report a Problem for billing or refund requests; the developer cannot issue refunds directly.
