HOW IT WORKS

操作流程示意，不是 App 页面截图
  1. 01

    打开设备信息

    查看设备型号、系统、存储容量及电池状态。

  2. 02

    查看网络状态

    在系统允许的范围内查看连接情况与网络详情。

  3. 03

    查看性能

    CPU 与内存展示使用公开接口及估算口径，不代表系统官方唯一数值。

  4. 04

    理解不可见项

    序列号、硬件温度、电池循环次数等未可靠开放的数据不会伪造。

使用前请注意

设备信息不是专业硬件诊断工具；某些数据受设备型号、系统权限和公共 API 限制。
